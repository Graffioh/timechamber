# Sublessons

Use this file for optional branches that come up at the end of a lesson.

At the end of each lesson, list concepts that were mentioned but not deeply
explained. Ask whether the learner wants to branch into one, continue the main
curriculum, or save the branch for later.

Statuses:

- `available`: identified but not started.
- `active`: currently being explored.
- `completed`: explored enough for now.
- `deferred`: intentionally saved for later.
